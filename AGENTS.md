# Работа с Unity

- Перед запуском Unity проверить, не открыт ли уже `/home/denis/Tiny Trouble`.
- Если проект уже открыт, использовать существующий редактор через Unity MCP.
- При необходимом перезапуске сначала сохранить сцены и ассеты, закрыть старый
  экземпляр и дождаться фактического завершения его процесса. Только затем
  запускать новый экземпляр. Не открывать второй редактор с этим же проектом.
